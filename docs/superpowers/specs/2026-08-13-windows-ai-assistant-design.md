# Windows AI 助手（assistant）设计文档

- 日期：2026-08-13
- 状态：已批准（4 节设计全部经用户确认）
- 路径分类：Architectural（全新项目）

## 1. 项目定位

一个运行在 Windows 10/11 64 位上的个人 AI 助手桌面应用，承担两个目标：

1. **聊天陪伴（情绪价值）**：固定人设 + 长期记忆，越用越懂用户。
2. **干活助手（协助工作）**：系统级智能体，能自主完成多步任务。

仅作者本人使用，不对外分发。

## 2. 需求汇总

| 维度 | 决策 |
|---|---|
| 形态 | 系统级智能体 + 聊天陪伴双线 |
| 模型来源 | 纯云端 API；抽象供应商接口，默认 DeepSeek |
| 操作权限 | B 级：文件 + 应用启停 + PowerShell + 浏览器自动化（查资料→抓取→呈现）；预留 C 级（键鼠控制）接口 |
| 自主程度 | B 级多步任务：目标 → 自动拆解 → 逐步执行 → 失败自纠 → 结果汇报；敏感操作默认确认 + 自动驾驶开关 |
| 交互 | 桌面聊天窗口 + 系统托盘 + 全局热键唤起；无语音输入输出 |
| 人设 | 可配置 system prompt + 预置模板；聊天线/任务线双人格分离 |
| 长期记忆 | 本地 SQLite，自动沉淀、去重消解、检索注入 |
| 技术栈 | Python 3.12 + PySide6（单体应用） |
| 分发 | PyInstaller 单文件 exe，仅个人使用 |
| 名称 | assistant |

## 3. 非目标

### v1 明确不做（留接口）
- 鼠标键盘控制（C 级，`tools/computer.py` 预留抽象接口）
- 语音输入输出
- 多用户 / 商业发布 / 自动更新
- 本地模型（Ollama 等）
- embedding 检索（接口预留，先用 FTS5）

### v1.5 计划（已确认，不在 v1）
- AI 主动发起对话：事件监听源（系统通知/邮件/定时）+ 打扰决策层（LLM 判断 + 勿扰模式）+ 主动弹出（toast/托盘/窗口消息）
- 提醒：自然语言解析定时任务（"明天下午 3 点提醒我开会"）+ APScheduler 调度 + 重复提醒/错过补偿
- 任务断点恢复

## 4. 架构方案

**方案一：单体 Python 应用**（已批准）。单进程，内部严格分层，模块只通过接口互相认识：

- `ui` 不知道模型和工具的存在
- `agent` 不知道 UI 的存在
- `tools` 不知道 agent 的存在

### 技术选型

| 组件 | 选择 | 理由 |
|---|---|---|
| 语言/运行时 | Python 3.12 | 生态最全 |
| UI | PySide6 (Qt6) | 窗口 + 托盘 + 富文本渲染一站解决 |
| 全局热键 | pynput | 顺带是未来 C 级（键鼠控制）的底层库 |
| 模型通信 | httpx 流式 + OpenAI 兼容协议 | DeepSeek/通义/Kimi 全是 OpenAI 协议，一个适配器通吃 |
| 浏览器自动化 | Playwright（独立线程，默认无头） | Windows 支持最好 |
| 存储 | SQLite（无 ORM，手写 SQL） | 单文件、零部署；记忆检索用 FTS5 |
| 任务调度 | APScheduler | v1.5 提醒直接用 |
| API key 安全 | Windows DPAPI 加密存储 | 不落明文 |
| 打包 | PyInstaller 单文件 exe | 个人使用足够 |
| 测试 | pytest（核心逻辑 TDD） | agent 循环、记忆、工具全部可单测 |

### 线程模型

- Qt 主线程只做 UI
- agent 任务在独立 worker 线程运行，通过 Qt 信号（线程安全）回传进度/结果
- Playwright 独占一个线程
- UI 永远不卡

### 目录结构

```
src/assistant/
├── main.py           # 入口
├── ui/               # 聊天窗口、会话列表、托盘、热键
├── core/             # 会话管理、流式输出、事件总线
├── agent/            # 多步任务引擎（规划/执行/自纠）+ 安全确认
├── tools/            # 文件、应用、PowerShell、浏览器；computer.py 留 C 级接口
├── providers/        # 模型供应商适配器（默认 DeepSeek）
├── memory/           # 长期记忆（提取/检索）+ 人设管理
├── storage/          # SQLite、配置、DPAPI 密钥
├── reminders/        # v1.5 占位（APScheduler）
└── events/           # v1.5 占位（主动对话监听）
```

## 5. Agent 多步任务引擎

### 消息双通道

每条消息先过意图分类（LLM 小调用）：
- **聊天线**：人设 + 记忆注入，纯对话
- **任务线**：走 agent 引擎

### 任务循环（Plan → Act → Observe → Reflect）

1. **规划**：目标拆成步骤列表，每步绑定工具
2. **执行**：按 function calling 协议调用工具，观察每步结果
3. **自纠**：某步失败 → 反思原因、换方案重试（上限 3 轮，防死循环）
4. **汇报**：自然语言总结干了什么、结果如何、有什么没搞定

约束：
- 中间执行细节不污染聊天历史（只存在于任务内部滚动上下文），聊天窗口只显示进度摘要
- 用户可随时点"停止"中断
- 步骤记录写 SQLite（有据可查；断点恢复留 v1.5）

## 6. 工具协议与工具集

```python
class Tool:
    name / description / parameters  # JSON Schema，供模型 function calling
    risk: low | high
    async execute(args) -> ToolResult  # ok/error + 输出 + 产物
```

| 工具 | 能力 | 风险 |
|---|---|---|
| files | 读/写/移动/复制/删除/搜索文件、列目录 | 删除/覆盖 = high |
| apps | 启动应用、关闭进程 | 关闭 = high |
| shell | 执行 PowerShell（60s 超时、输出截断 8KB、禁交互等待） | high |
| browser | 搜索 → 打开 → 抓取正文/表格 → 卡片呈现（来源 + 摘要） | low |
| computer | C 级预留：键鼠/截图抽象接口，v1 空实现，pynput 就位 | —— |

## 7. 安全模型

- **默认模式**：low 风险直接执行；high 风险弹确认卡片（嵌在聊天流里，非打断式弹窗）
- **自动驾驶开关**：开启后 high 风险自动执行，但执行前在聊天里明示"即将执行：xxx"；随时可关
- **全局紧急停止**：任何模式下立即终止当前任务
- **模型系统提示约束**：不可越权、失败如实报告、破坏性操作（格式化、注册表大改等）除非用户明说否则禁止

## 8. 长期记忆

- **存储**：SQLite 表 `memories`（内容、类型、标签、重要度、创建/最近访问时间、访问次数、来源会话）
- **类型**：① 事实（"我在杭州工作"）② 偏好（"报告喜欢简洁风格"）③ 事件（"上周去体检了"）
- **沉淀**：每轮会话后台异步提炼新记忆；自动去重与冲突消解（新事实覆盖旧事实，按 topic 判定）
- **检索**：每次发消息注入 top-K 相关记忆 —— FTS5 关键词 + 时间衰减 + 重要度加权；不引入 embedding（DeepSeek 无 embedding API，本地模型太重），检索器接口预留 embedding 位
- **管理**：设置界面可查看/删除/一键导出/一键清空

## 9. 人设系统

- 预置多个人设模板 + 默认"温和能干的助理"
- 用户可在设置里自定义 system prompt
- **双人格分离**：聊天线用用户人设（陪伴口吻）；任务线用"执行者"提示（冷静高效）；任务汇报切回聊天线口吻

## 10. 会话管理

- 会话列表：新建/重命名/删除/全文搜索历史会话；历史消息存 SQLite
- 上下文窗口管理：接近模型上限时自动截断（保留最近 N 轮 + 自动摘要前缀）

## 11. 界面

- 主窗口：左会话列表 + 右对话区（流式输出、Markdown 渲染、代码高亮）
- 工具执行以活动卡片嵌在对话流里：进度、每步状态、确认按钮、结果摘要；抓取的网页呈卡片（来源链接 + 摘要 + 正文节选）
- 托盘菜单：打开主窗 / 自动驾驶开关 / 退出
- 全局热键：默认 Ctrl+Alt+Space 唤起/隐藏（可改）
- 可选开机自启（设置项）

## 12. 数据与配置

```
%APPDATA%\assistant\
├── assistant.db        # SQLite：会话、消息、记忆、任务步骤、设置
├── config.json         # 用户设置（模型、热键、自动驾驶默认态等）
├── secrets.dat         # API key，DPAPI 加密存储（不落明文）
└── personas\           # 人设模板
```

- Schema 版本化：`schema_version` 表 + 顺序迁移脚本，升级不丢数据
- 卸载即删这一个目录，零残留

## 13. 打包与分发

- PyInstaller `--onefile --windowed`，单 exe + 图标
- Playwright chromium 不塞进 exe，首次使用时自动下载到数据目录
- 构建脚本本地跑，不搞 CI

## 14. 测试策略（TDD）

- 核心逻辑全部先写测试：
  - agent 循环（mock 模型）
  - 记忆系统（提取/去重/检索）
  - providers（mock HTTP）
  - 文件工具（临时目录实测）
- UI 手工验证（Qt 自动化测试成本不值）
- 浏览器工具用本地测试页集成测试，不依赖外网

## 15. 开发顺序

1. 存储层（SQLite schema + 迁移）
2. 模型适配器（providers，DeepSeek 流式）
3. 聊天窗口（流式跑通）
4. 工具集（files/apps/shell/browser）
5. agent 引擎（多步循环 + 安全模型）
6. 记忆系统（提取/检索/消解）
7. 人设 + 会话管理完善
8. 托盘 / 热键
9. 打包 exe
